# كاميرات مفتوحة — إسرائيل

دليل كاميرات إسرائيلية مكشوفة على الإنترنت بلا كلمة مرور. كل بطاقة تُفتح بزر واحد، وكل صورة تُسحب عبر API داخلي (لأن الأجهزة على HTTP والموقع على HTTPS، وأيضًا بسبب CORS).

## القاعدة الحاكمة

- **لا mock.** لا يوجد أي رابط يُكتب يدويًا في الواجهة: القائمة كلها مأخوذة لحظيًا من المصادر ثم تُفحص صورةً صورة.
- **البروكسي فلتر الحياة:** إذا لم تُرجع الكاميرا صورة JPEG صالحة (أكبر من 2.5KB) تُستبعد من القائمة نهائيًا.
- **قراءة فقط.** لا تعديل على إعدادات أي جهاز.

## المسارات

| المسار | الدور |
| --- | --- |
| `GET /api/cameras` | يحكّ insecam (صفحات 1..8) و opencctv، ينظّف الروابط من `COUNTER`، يوحّد ويزيل التكرار، ثم يفحص كل رابط فعليًا ويُرجع الحيّ فقط. كاش داخلي 5 دقائق. |
| `GET /api/frame/[id]` | يرجّع إطار JPEG (يدعم اللقطات وموجات MJPEG عبر استخراج أول إطار من تدفّق multipart). يرجّع 502 إذا كانت الكاميرا ميتة. |
| `GET /api/stream/[id]` | نفس الجلب بلا تخزين، لتحديث العرض المكبّر. |
| `/cam/[id]` | صفحة المشاهدة. |

المعرّف `id` هو base64url للرابط الكامل، فلا يُبنى أي استعلام على العميل.

## التشغيل

```bash
npm install && npm run dev
```

ثم افتح http://localhost:3000. على Vercel لا يلزم أي إعداد إضافي (Node runtime، بلا متغيّرات بيئة).

## البنية

- `lib/sources.ts` — استخراج سجلات insecam و opencctv من HTML، حذف وسيط `COUNTER`، المدينة من `Live camera in <CITY>, Israel`.
- `lib/frames.ts` — تحقّق من سلامة JPEG، واستخراج أول إطار من تدفّقات `multipart/x-mixed-replace`.
- `lib/http.ts` — بروكسي احتياطي عام + حدّ تزامن + مهلة.
